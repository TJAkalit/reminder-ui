# Сравнение UI-библиотек

> Статус: **выбран Mantine** (2026-10-18, D-012). Документ сохранён как обоснование.

## Что нужно приложению

- Дашборд «Сегодня»: карточки рутин, список привычек с чекбоксами/статусами.
- Таблица/список привычек: расписание, текущая и лучшая серия, значки milestones.
- Страница привычки: **heatmap** выполнения (как контрибуции на GitHub), график %.
- Позже: формы создания/редактирования, выбор времени и дней недели (time picker).
- Хорошо на телефоне (смотреть будут в основном с него), тёмная тема.
- Возможное будущее: открывать UI как **Telegram Mini App** — нужна гибкая тема.

### PatternFly

\+ Продуманная дизайн-система, отличная доступность, мощные таблицы и toolbar.
− Ориентирован на админки корпоративного ПО: выглядит «как OpenShift-консоль», тяжёлый,
desktop-first. Для личного трекера привычек это избыточно и визуально «не то».
Имеет смысл, если цель — прокачать именно PatternFly (например, для работы).

### React Bootstrap

\+ Просто, знакомо, лёгкий, хорошая сетка и мобильность.
− Компонентов мало: нет date/time picker, графиков, хуков форм, уведомлений — всё
добирается сторонними библиотеками разного качества и стиля. Выглядит «по-бутстраповски».

### Mantine (рекомендация)

\+ Из коробки покрывает почти всё, что нужно: карточки, бейджи, `RingProgress` для серии,
`@mantine/dates` (TimeInput, выбор дней), `@mantine/charts`, `@mantine/notifications`,
`@mantine/form`. Отличный TS, удобная тёмная тема, CSS-модули/CSS-переменные без
runtime CSS-in-JS. Легко подстроить тему под Telegram Mini App.
− Меньше «enterprise-таблиц», чем в PatternFly (для нашего объёма не нужно).

### Другие

- **MUI** — мощно, но Material-вид и вес; MUI X частично платный.
- **shadcn/ui + Tailwind** — максимум контроля и современный вид, но больше ручной работы
  и требует Tailwind; хороший выбор, если хочется изучить Tailwind.

## Рекомендация

1. **Mantine** — лучший баланс «быстро сделать MVP» и «есть куда расти».
2. Если важно сравнить именно из предложенных двух: **React Bootstrap** ближе к задаче,
   чем PatternFly, но потребует больше сторонних библиотек.
3. PatternFly — только если цель изучить его ради работы.

Heatmap: проверить при выборе — компонент `Heatmap` в `@mantine/charts` (новые версии) или
отдельная библиотека `react-activity-calendar` (работает с любой UI-библиотекой).

## Как проверить перед финальным решением (spike, ~1–2 ч)

Сверстать одну страницу «Сегодня» с моковыми данными на 2 кандидатах (Mantine и
React Bootstrap), посмотреть на телефоне, сравнить объём кода и размер бандла
(`vite build` → размер `dist/assets`).
