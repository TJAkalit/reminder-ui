# reminder-ui

Веб-интерфейс трекера привычек Reminder: привычки, расписания, серии и значки.

```bash
npm install
npm run dev        # нужен запущенный reminder-backend (`uv run reminder api`)
npm run dev:mock   # или без бэкенда, на моковых данных
```

Подробности — в [`AGENTS.md`](AGENTS.md), задачи — в [`TASK.md`](TASK.md).
